## 🧭 Philosophy

Local-first by default. Your data stays in `~/.skales-data` on your machine. Bring your own keys. No Docker. No terminal. No signup. 30-second install.

Built from **6 to 60+** — usable by a kid, approved by a grandmother. Mainstream surface, power-user depth underneath. That's the moat.

## ✨ Hero Features

🛠️ **Codework** — Autonomous coding agent with 3-panel diff GUI, session history, undo support

🏢 **Organization** — Build an AI company with departments, specialized agents, and team leaders

🦁 **Lio AI** — Block-based code builder for newcomers, generates HTML/CSS/JS/Python in sandboxed preview

🎨 **Studio** — Design, image, video, voice, and music generation from one place

🌐 **Built-in Browser** — Agent navigates websites, clicks buttons, extracts content

🖥️ **Computer Use** — Screenshot, click, type, scroll — your agent sees and controls your screen

📅 **Planner + Calendar Sync** — Daily/weekly planning with Google, Apple, Outlook integration

🧠 **Memory + Dreaming** — Persistent memory with 3-phase overnight consolidation

🌍 **15+ AI Providers** — Cloud (OpenAI, Anthropic, Google, Groq, DeepSeek, xAI, ...) and local (Ollama, LM Studio)

🌐 **12 Languages** — EN, DE, ES, FR, RU, PT, KO, ZH, JA, VI, HR, TR
